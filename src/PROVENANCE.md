# Reconstructed source provenance

The initial translation units and included project headers in this directory are
byte-for-byte copies from the `v1.8.0` tag of
`https://github.com/blupi-games/planetblupi` (commit `203ccc8`), licensed
GPLv3+.

Copied translation units: `sound.cpp`, `movie.cpp`, `misc.cpp`, and
`ddutil.cpp`. Their copied header dependency closure is `ddutil.h`, `def.h`,
`misc.h`, `movie.h`, `resource.h`, and `sound.h`. Original bytes and line
numbers are preserved; provenance is recorded here rather than in source
comments because `__LINE__` affects generated code and data.

The matching verifier compiles these files in the canonical flat layout under
their original filenames. Any later header changes needed for compilation must
be recorded here with the reason and affected file.
